# ADR-008: 配置版本与发布配置快照

状态：Accepted | 日期：Phase 0

## 决策
所有影响发布的配置（流程、环境、Jenkins、Git、部署、健康检查、版本检查、通知、报警、权限规则）写入 `config_version` 版本化管理。发布计划启动时复制当前生效配置生成 `ReleaseConfigSnapshot`，执行期只读快照。管理员后续修改不影响进行中/历史发布。

## 规则
- 配置变更产生新版本号（V1→V2→…），记录修改人/时间/before/after。
- 快照以 JSON 存储 + 关键字段冗余列，便于审计展示。
- 配置读取统一经 `ConfigService`（DB → 缓存 → 快照），业务代码禁止硬编码环境/项目/Job/分支判断。
