# specs/ — Specification 驱动开发目录

每个 Feature 一个目录，进入对应 Phase 时填充完整内容。

每个 Specification 包含：

```
README.md        概述与状态
requirements.md  用户故事/业务规则/前置后置条件/异常/权限/状态转换/验收标准
design.md        领域模型与设计
api.md           API Contract
data-model.md    数据模型
test-plan.md     测试计划（含 TDD 用例基线）
acceptance.md    验收清单
```

模板见 `SPEC_TEMPLATE.md`。索引见 `IMPLEMENTATION_PLAN.md`。
