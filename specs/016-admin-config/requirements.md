# Requirements — 管理员配置中心与配置版本

## 用户故事

- 作为管理员，我修改任何影响发布的配置都会产生新版本并可查看 当前值 vs 新值/修改人/时间。

## 业务规则

- 影响发布的配置变更必须创建新版本(§三十三)；版本号同 key 单调递增。
- diff 输出字段级差异(path/before/after)；已生成的 ReleaseConfigSnapshot 永不回改。

## 前置条件

- 依赖的上游 Phase/Spec 已完成；相关配置资源已就绪。

## 后置条件

- 本规格范围内数据落库一致，领域事件/审计/日志按规范产出。

## 异常情况

- 并发修改同 key → 乐观锁 CONFLICT

## 权限

- `config:admin`

## 验收标准（摘要）

- 修改 N 次产生 N 个版本且互不影响
